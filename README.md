# ₽ → ⏱ Рубли в Часы

Расширение для браузера, которое автоматически переводит цены в рублях в часы работы. Видишь цену — сразу понимаешь, сколько часов жизни она стоит.

## Установка

Расширение не опубликовано в магазинах, поэтому устанавливается вручную в режиме разработчика.

### Google Chrome / Yandex Browser / Microsoft Edge

1. Скачай или клонируй этот репозиторий на компьютер:
   ```
   git clone https://github.com/DmitriyErshov/rubles-to-hours.git
   ```
   Или скачай ZIP через кнопку **Code → Download ZIP** на GitHub и распакуй.

2. Открой страницу расширений в браузере:
   - **Chrome**: введи в адресную строку `chrome://extensions`
   - **Yandex Browser**: `browser://extensions`
   - **Edge**: `edge://extensions`

3. Включи **Режим разработчика** (переключатель в правом верхнем углу).

4. Нажми **«Загрузить распакованное расширение»** (или «Load unpacked»).

5. Выбери папку с репозиторием (ту, где лежит `manifest.json`).

6. Расширение появится в списке и будет готово к работе.

### Firefox

Firefox пока не поддерживается (расширение использует Manifest V3).

## Использование

1. Нажми на иконку расширения в панели браузера.
2. Введи свою почасовую ставку в рублях.
3. Включи расширение — все цены на страницах заменятся на часы работы.

## Обновление

Если скачал через `git clone`, достаточно выполнить `git pull` в папке репозитория. Перезагружать расширение вручную через страницу расширений не нужно — изменения применяются автоматически.

Если скачивал ZIP — повтори шаги установки с новым архивом.
